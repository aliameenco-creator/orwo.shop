A hand-built WooCommerce storefront for photos, DVDs, Blu-ray, posters, vinyl and CDs.

== Description ==

ORWO is the storefront theme for orwo.shop. It brings its own templates, filters, URLs, homepage and the Ask ORWO
chatbot, and keeps WooCommerce as the order engine with its cart, checkout and account pages styled to match.

The catalogue itself lives in the ORWO Core plugin, so a redesign never touches the products. The theme needs that
plugin and WooCommerce to be active.

No page builder, no framework, no jQuery on browsing pages: one stylesheet and one small deferred script.
